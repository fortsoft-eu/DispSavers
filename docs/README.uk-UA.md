FlyingSolids показує об’ємні тіла, які рухаються, обертаються й стикаються. Виберіть спостереження за простором або політ крізь нього та потрібні тіла. Для кожного монітора окремо задаються швидкості об’єктів і камери 0–1600%, розмір 50–200% та 1–10 копій кожного тіла. Основне, заповнювальне, фонове й контурне світло вмикаються незалежно.

## Керування

Виберіть один або кілька рядків у списку моніторів. Ctrl+A вибирає всі; Ctrl і Shift змінюють вибір. Елементи керування й повзунки анімації змінюють лише налаштування вибраних моніторів. Вибір рядка та ввімкнення виведення його прапорцем — різні дії. Вибір зберігається окремо для програми й заставки. Якщо раніше були вибрані всі монітори, до вибору долучаються й новопідключені.

## Програма

Запустіть FlyingSolids.exe. Налаштування зберігаються постійно, працює лише один екземпляр програми. Прапорець монітора або подвійне клацання рядка вмикає чи вимикає виведення анімації. Анімацію можна призупинити та продовжити. PNG і MP4 захоплюють перший активний монітор анімації, а не спільне зображення всіх моніторів. Монітор, який записується, вимкнути не можна; закриття програми під час запису потребує підтвердження. Блокування заставки діє для всього сеансу й лише доки на моніторі з цією опцією видима непризупинена анімація. Програма може встановити або видалити вбудовану заставку.

У налаштуваннях запису виберіть Viewport або TV. Viewport зберігає розміри та частоту монітора до 60 кадрів за секунду. TV пропонує 1920 × 1080, 1440 × 1080 або 1280 × 720 зі співвідношенням 16:9 і частотою 50, 25, 59.94 (60000/1001) або 29.97 (30000/1001) кадрів за секунду. Відео TV прогресивне, BT.709, з обмеженим діапазоном і субдискретизацією кольору 4:2:0. Пропорції зберігаються, смуги заповнення чорні. OK зберігає вибір для наступного запису; Скасувати або Esc відхиляє непідтверджені зміни. Вікна запису, довідки та відомостей не блокують інші вікна й можуть згортатися. Tab і Shift+Tab переміщують фокус, Enter активує кнопку з фокусом, Esc закриває активне допоміжне вікно.

## Заставка

Використовуйте FlyingSolids.scr як заставку Windows з окремими налаштуваннями. Повноекранний попередній перегляд дозволяє змінювати їх під час анімації. OK зберігає зміни, Скасувати або Esc відхиляє їх. Для виходу із заставки натисніть клавішу або порухайте мишею.

## Системні вимоги

Windows 7–11 підтримує всі функції. Для Windows Vista SP2 потрібно встановити оновлення KB971512 і KB2117917; запис MP4 у Vista не працює. Потрібна підтримка Direct3D 11, а для MP4 також Media Foundation й кодувальник H.264. Інтерфейс і документація доступні 36 мовами.

## Збирання та пакування

Відкрийте DispSavers.slnx у Visual Studio та зберіть Release | x86 з MSVC v145 і Windows SDK. На сторінці Signing задайте сертифікат і обов’язковий сервер часових позначок RFC 3161; особисті значення залишаються в ігнорованому .vcxproj.user. Підписаний SCR із часовою позначкою вбудовується в EXE, після чого підписується й EXE. PackageRelease.ps1 створює спільний архів `DispSavers-<version>-win32.zip` без зміни двійкових файлів у Release.
