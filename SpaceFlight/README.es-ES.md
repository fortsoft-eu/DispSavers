SpaceFlight: Superficie ondulante infinita; Vuelo de larga distancia — superficie deformable. Asigne una sola animación a cada pantalla. Textura alterna entre superficies texturizadas y modelo de alambre. El giro libre de la cámara cambia lentamente la dirección de la vista en las tres dimensiones. La opción «Pausas e inversiones» añade frenadas, pausas e inversiones aleatorias del giro; el vuelo hacia delante continúa. La velocidad va del 0 al 1600 %. Cada pantalla tiene una escena aleatoria independiente y se renderiza a su propia frecuencia de actualización. La luz principal, la luz de relleno, la luz ambiental y la iluminación de contornos se activan por separado para las pantallas seleccionadas. La iluminación solo se aplica a las superficies texturizadas. Desactivar Ondulación aplana ambas superficies sin detener el vuelo ni el giro de la cámara.

La selección de filas determina qué pantallas se están configurando; es independiente de las casillas que activan las salidas de animación. Ctrl+A selecciona todas; Ctrl y Mayús modifican la selección. Todas las opciones y los controles deslizantes de animación se aplican a las pantallas seleccionadas. La selección se recuerda por separado para EXE y SCR. Si estaban seleccionadas todas, se incluyen también las nuevas.

## Aplicación

`SpaceFlight.exe`

Seleccione varios monitores en la lista; un doble clic alterna la animación en un monitor y también puede desmarcarlos todos. Cada monitor usa una escena independiente. Captura guarda un PNG y el botón de grabación inicia o detiene un MP4. Pausar detiene la animación. La aplicación instala o desinstala además el salvapantallas incorporado. Los ajustes se guardan continuamente. La aplicación solo permite una instancia. Al volver a iniciarla, restaura la ventana de control minimizada y la trae al primer plano. Use Tab y Mayús+Tab para desplazarse entre controles; Alt y la letra subrayada activan una opción. Esc cierra la ventana activa de Ayuda o Acerca de; en la ventana de control, sale de la aplicación. Bloquear salvapantallas durante la animación impide que se inicie el salvapantallas de Windows solo mientras la animación está realmente visible y no está en pausa.

Las capturas y grabaciones usan el primer monitor de animación activo, no una imagen conjunta de todos los monitores. PNG usa Imágenes y MP4 Vídeos; si no existen esas carpetas, se usa Documentos. El botón Ajustes de grabación permite elegir Viewport o TV. Viewport conserva las dimensiones y la frecuencia de actualización del monitor de animación, hasta 60 fotogramas por segundo. TV ofrece 1920 × 1080, 1440 × 1080 o 1280 × 720 en formato 16:9, a 50, 25, 59.94 (60000/1001) o 29.97 (30000/1001) fotogramas por segundo. Se conserva la relación de aspecto; TV usa vídeo progresivo BT.709 de rango limitado y submuestreo 4:2:0. La resolución y la frecuencia solo están disponibles en modo TV. La ventana Ajustes de grabación se puede minimizar y no bloquea las demás ventanas de la aplicación. Aceptar guarda las opciones para la próxima grabación MP4; Cancelar o Esc descarta los cambios sin confirmar. El monitor grabado no se puede desmarcar durante la grabación; cambiar otros monitores no la detiene. Cerrar la aplicación durante una grabación requiere confirmación porque también detiene la grabación.

Windows 7 a Windows 11 admiten todas las funciones, incluidas las capturas PNG y la grabación MP4. Para ejecutar la aplicación en Windows Vista SP2, es necesario instalar las actualizaciones KB971512 y KB2117917. La grabación MP4 no funciona en Vista en la versión actual.

## Protector de pantalla

`SpaceFlight.scr`

Activar vista previa inicia una vista previa a pantalla completa en todos los monitores; el cuadro de configuración permanece abierto para realizar ajustes en tiempo real. Aceptar guarda y Cancelar descarta. Esc o mover el ratón cierra el salvapantallas completo. Use Tab y Mayús+Tab para desplazarse entre controles; Alt y la letra subrayada activan una opción. Esc en la configuración equivale a Cancelar; en Ayuda o Acerca de, cierra únicamente esa ventana.

Se admiten Windows 7 a Windows 11. Para ejecutar la aplicación en Windows Vista SP2, es necesario instalar las actualizaciones KB971512 y KB2117917.

## Compilación

Abra `DispSavers.slnx` en Visual Studio con MSVC v145 y un SDK de Windows. Seleccione `Release | x86` y recompile la solución para generar `Release\SpaceFlight.exe` y `Release\SpaceFlight.scr`. No hay configuración x64. En las propiedades del proyecto `SpaceFlight`, página `Signing`, indique el nombre o la huella de un certificado válido de firma de código con clave privada en el almacén `Personal (My)` del usuario actual. Los ajustes se aplican al EXE y al SCR y se guardan en `SpaceFlight.vcxproj.user`, ignorado por Git. SignTool se busca automáticamente en PATH o en el SDK de Windows. Si usa SimplySign, inicie sesión en SimplySign Desktop antes de compilar. Primero se firma el SCR y se añade un sello de tiempo RFC 3161 SHA-256 obligatorio del servidor de sellado de tiempo configurado; después se incorpora al EXE, que también se firma y recibe un sello de tiempo. Indique la URL del servidor de sellado de tiempo RFC 3161 en el campo `Timestamp server`. Cualquier error de firma, sellado de tiempo o verificación detiene la compilación; los archivos con firmas válidas y sello de tiempo no se vuelven a firmar.
