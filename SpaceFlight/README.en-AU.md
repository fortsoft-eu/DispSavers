SpaceFlight: Infinite undulating surface; Long-distance flight — morphing surface. Assign exactly one animation to each display. Texture switches between textured surfaces and wireframe. Free camera rotation slowly changes the viewing direction in all three dimensions. The Pauses and reversals option adds randomised braking, pauses and reversals of the rotation; forward flight continues. Animation speed ranges from 0–1600%. Every display has an independent randomised scene rendered at its own refresh rate. Main light, fill light, ambient light and rim light can be switched independently for the selected displays. Lighting applies only to textured surfaces. Turning off Waves makes both surfaces flat without stopping flight or camera rotation.

Row selection determines which displays you are editing; it is separate from the checkboxes that enable animation outputs. Ctrl+A selects every display; Ctrl and Shift adjust the selection. All animation options and sliders apply to the selected displays. The selection is remembered separately for EXE and SCR. If all displays were selected, newly connected displays join the selection. Different values across selected displays are indicated by indeterminate checkboxes and dotted radio buttons, slider thumbs and buttons for enabling or disabling all options. Slider labels show a dash instead of a shared value. Changing an option or clicking a slider applies that value to all selected displays.

## Application

`SpaceFlight.exe`

Enable or disable animation outputs using the display checkboxes or by double-clicking their rows. Each display uses an independent scene. Snapshot saves PNG and the recording button starts or stops MP4. Pause stops the animation. The application also installs or uninstalls its embedded screen saver. Settings are saved continuously. Only one instance of the application runs at a time. Launching it again restores its minimised control window and brings it to the foreground. Use Tab and Shift+Tab to move between controls; use Alt and the underlined letter to activate a command. Esc closes the active Help or About window; in the control window, it exits the application. Pause and screen-saver blocking apply to the whole application, regardless of display selection. When blocking is enabled, the Windows screen saver is prevented only while unpaused animation is visible on at least one display.

Snapshots and recordings capture the first active animation display, not a combined image of all displays. PNG uses Pictures and MP4 uses Videos, with Documents as the fallback if those folders do not exist. The Recording settings button selects Viewport or TV. Viewport preserves the animation display’s dimensions and refresh rate, up to 60 frames per second. TV offers 1920 × 1080, 1440 × 1080 or 1280 × 720 output in 16:9, with 50, 25, 59.94 (60000/1001) or 29.97 (30000/1001) frames per second. The image keeps its aspect ratio; TV uses progressive BT.709 limited-range 4:2:0 video. Resolution and frame rate are available only in TV mode. The Recording settings window can be minimised and does not block the other application windows. OK saves choices for the next MP4 recording; Cancel or Esc discards unconfirmed changes. The recorded display cannot be detached during recording; changes to other displays do not stop the recording. Closing the application while recording requires confirmation because it also stops the recording.

Windows 7 through Windows 11 support all features, including PNG snapshots and MP4 recording. To run the application on Windows Vista SP2, you must install updates KB971512 and KB2117917. MP4 recording does not work on Vista in the current version. Rendering requires Direct3D 11, not just an older DirectX runtime. MP4 recording requires available Media Foundation components and an H.264 encoder.

## Screen saver

`SpaceFlight.scr`

Enable preview starts a full-screen preview on every display and allows live adjustments while the settings dialog remains open. OK saves the settings and Cancel discards them. Exit the full-screen screen saver with Esc or mouse movement. Use Tab and Shift+Tab to move between controls; use Alt and the underlined letter to activate a command. Esc in the settings dialog is equivalent to Cancel; in Help or About, it closes only that window.

Windows 7 through Windows 11 are supported. To run the application on Windows Vista SP2, you must install updates KB971512 and KB2117917. Rendering requires Direct3D 11, not just an older DirectX runtime.

## Building

Open `DispSavers.slnx` in Visual Studio with MSVC v145 and a Windows SDK. Select `Release | x86` and rebuild the solution to produce `Release\SpaceFlight.exe` and `Release\SpaceFlight.scr`. No x64 configuration is provided. In the `SpaceFlight` project properties, on the `Signing` page, enter the name or thumbprint of a valid code-signing certificate with a private key in the current user's `Personal (My)` store. The settings apply to both EXE and SCR and are saved in the Git-ignored `SpaceFlight.vcxproj.user` file. SignTool is located automatically in PATH or the Windows SDK. If you use SimplySign, sign in to SimplySign Desktop before building. The build first signs SCR and adds a mandatory RFC 3161 SHA-256 timestamp from the configured timestamp server, then embeds it in EXE, which is also signed and timestamped. Enter the RFC 3161 timestamp server URL in the `Timestamp server` field. Signing, timestamping, or verification failure stops the build; binaries with existing valid timestamped signatures are not signed again.
